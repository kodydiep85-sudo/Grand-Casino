GRAND SQUEEZE CASINO - WEBSITE FILES (22 files, no folders)

PUT IT ONLINE
1. GitHub: open your repository > Add file > Upload files.
   Select ALL the files in this folder (not the folder itself), drag them in, click Commit changes.
   If GitHub says some files failed: upload just those files again (smaller batches are fine).
2. Render redeploys by itself a minute or two after you commit.
   (First time? Render: New > Web Service > pick the repository. Start Command: node server.js)
3. CHECK IT: open  your-site.onrender.com/check
   It lists every file the site needs with a tick or a cross. Any cross: upload that file again.
